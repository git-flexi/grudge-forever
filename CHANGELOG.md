# GrudgeForever 1.1.0

### New
- **Sortable columns.** Click a column header in the main window to sort by it, click it again to turn the order around. An arrow shows the sorted column. Lists start with the newest entries on top, the guild tab with the members seen most recently.
- **Update notice.** GrudgeForever tells you in the chat when a newer version is available. It learns about new versions from guildmates and group members who run GrudgeForever, and shows the notice once per session.

### Changed
- **Names look like in the game.** Every word of a name starts with a capital letter, however you type it. "spitz ohr" is saved and shown as "Spitz Ohr". Names you added earlier are tidied up automatically.
- Warnings keep working whatever the casing: "SPITZ OHR", "spitz ohr" and "Spitz-Ohr" are the same player.
